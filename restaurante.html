Como este cardápio trata seus dados

O cardápio usa o Supabase para exibir produtos, preços e disponibilidade. Quando você escolhe entrega, a localização ou o endereço informado é enviado à nossa Edge Function apenas para calcular a distância e a taxa; a chave do serviço de rotas fica protegida no servidor.

Os dados do checkout são usados para montar a mensagem do WhatsApp. Se você escolher pagamento online, os dados necessários do pedido são enviados à InfinitePay para gerar o checkout. Esta página não marca um pedido como pago apenas por abrir o pagamento ou copiar uma chave Pix. O carrinho pode ficar salvo localmente no seu navegador para facilitar a continuidade do pedido. Não usamos rastreadores de publicidade neste projeto.
