IMPORTANTE SOBRE O AMBIENTE
---------------------------
A política administrativa deste ambiente bloqueia navegação direta do Chromium para URLs HTTP/HTTPS/localhost (ERR_BLOCKED_BY_ADMINISTRATOR).
Por isso, os arquivos EXATOS HTML/CSS/JS do projeto foram carregados dentro do Chromium real e as interações foram executadas por clique/preenchimento como um cliente real. As chamadas externas de rota/pagamento foram simuladas no formato esperado das APIs para validar fluxo, DOM, cálculos, mensagens e estados sem depender da rede bloqueada.
A lógica de integração da InfinitePay foi conferida com o endpoint oficial do Checkout Integrado: POST https://api.checkout.infinitepay.io/links.

ANTES DE PUBLICAR
-----------------
1. Execute EXECUTAR_NO_SUPABASE_V25.sql no SQL Editor do Supabase.
2. Publique as Edge Functions com ATUALIZAR_EDGE_FUNCTION_V25.bat (ou pela CLI Supabase).
3. No InfinitePay, habilite Checkout Integrado.
4. No ADM > Pagamentos, informe a InfiniteTag sem o símbolo $ e configure Pix/crédito/débito.
5. Publique os arquivos do site no GitHub Pages.
6. Teste a conta InfinitePay real com um pedido de baixo valor antes de liberar para clientes.

Observação: abrir o checkout ou copiar Pix NÃO é confirmação de pagamento. Esta versão preserva essa distinção.
