Privacidade

Como este cardápio trata seus dados

O cardápio usa o Supabase para exibir produtos, preços e disponibilidade. Quando você escolhe entrega, a localização ou o endereço informado é enviado à nossa Edge Function apenas para calcular a distância e a taxa; a chave do serviço de rotas fica protegida no servidor.

Os dados preenchidos no checkout são usados para montar a mensagem do WhatsApp. O carrinho e o histórico de pedidos podem ficar salvos somente neste navegador para facilitar a continuidade e a repetição de pedidos. A chave Pix cadastrada pelo restaurante aparece apenas na comanda do WhatsApp quando Pix for escolhido. Não usamos rastreadores de publicidade neste projeto.
